## Key Gotchas Found & Fixed

- `next dev --webpack` needed `--max-old-space-size=8192` in `package.json` to prevent OOM during monorepo route compilation.
- Postgres Payload `id` fields are numeric serials: passing string `routeParams.id` or `String(doc.id)` into relationship `create`/`find` fails validation → pass `post.id` / `doc.id` cleanly.
- Payload global endpoints whose first segment matches a collection slug (`posts`, `polls`) are shadowed by collection router → moved to `collection.endpoints`.
- `file-type@22.0.1` added directly to `apps/undrepost/package.json` because pnpm `isolated` linker hid it from Next `serverExternalPackages`, breaking `GET /api/media/file/*`.
- `Media` `beforeOperation` must update `file.size` after sanitizing SVG bytes, otherwise `buildUploadOutput`'s `buffer.length !== file.size` probe guard drops the file write.
